# Slice 04: Home Page

## Objective

Build a conversion-focused home page that improves the original Casas RM homepage visually and structurally.

## Scope

- Replace the starter page at `app/page.tsx`.
- Compose the page from reusable sections and static content.
- Prioritize SEO-readable server-rendered content.

## Required Sections

- Hero with strong construction CTA.
- Service highlights.
- About preview.
- Values grid.
- Featured projects.
- Metrics band.
- Final CTA.

## Suggested Copy Direction

Hero title:

`Construye la casa de tus suenos con confianza`

Hero subtitle:

`Disenamos, construimos, ampliamos y remodelamos hogares en Chile con materiales de calidad, gestion clara y acompanamiento profesional desde la idea hasta la entrega.`

Primary CTA:

`Cotiza tu proyecto`

Secondary CTA:

`Ver proyectos`

## Deliverables

- Home page implementation.
- Section components as needed.
- CTA links wired to `/contacto`, `/proyectos`, and WhatsApp.

## Acceptance Criteria

- Above the fold explains what the business does.
- Main CTA is visible without scrolling on desktop and mobile.
- The page feels more premium than the reference site.
- Content remains readable without client-side JS.

## Verification

- Desktop and mobile visual check.
- `npm run lint`
- `npm run build`
